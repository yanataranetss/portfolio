# Checklist de Documentación para Declaración IRPF

## ✅ Documentos Obligatorios

### 📄 Ingresos del Trabajo
- [ ] Certificado de retenciones e ingresos (modelo 190) del empleador
- [ ] Nóminas del año completo
- [ ] Contrato de trabajo
- [ ] Datos de la empresa (CIF, razón social)

### 📄 Ingresos de Actividades Económicas (Freelance)
- [ ] **Facturas emitidas T1 (Enero-Marzo)**
- [ ] **Facturas emitidas T2 (Abril-Junio)**
- [ ] **Facturas emitidas T3 (Julio-Septiembre)** ✓ (Subidas)
- [ ] **Facturas emitidas T4 (Octubre-Diciembre)**
- [ ] Certificados de retenciones (modelo 100) de clientes
- [ ] Libro registro de ingresos
- [ ] Alta en Hacienda (modelo 036/037)

### 📄 Gastos Deducibles (con Justificantes)
- [ ] Recibos Seguridad Social (cuotas autónomos)
- [ ] Material de oficina y suministros
- [ ] Software y herramientas profesionales
- [ ] Gastos de formación profesional
- [ ] Gastos de vivienda (si aplicable):
  - [ ] Recibos de alquiler o IBI
  - [ ] Facturas de luz
  - [ ] Facturas de agua
  - [ ] Facturas de internet
  - [ ] Factura de teléfono (línea profesional)
  - [ ] Justificante de metros dedicados a actividad
- [ ] Gastos de desplazamiento profesional
- [ ] Gastos financieros (comisiones bancarias cuenta profesional)
- [ ] Asesoría fiscal y contable
- [ ] Seguros profesionales

### 📄 Pagos a Cuenta
- [ ] Modelos 130 presentados (pagos fraccionados)
- [ ] Justificantes de pago trimestral (si aplicable)

### Deducciones Estatales
- [ ] Aportaciones a planes de pensiones

- [ ] Alquiler de vivienda habitual (menores 35 años)

### Deducciones Autonómicas
- [ ] Gastos educativos
- [ ] Nacimiento/adopción
- [ ] Personas con discapacidad a cargo
- [ ] Otras específicas de tu comunidad autónoma

## 📅 Calendario y Plazos

### Trimestral (Freelance)
- [ ] Modelo 130 (Pago fraccionado) - Días 1-20 del mes siguiente al trimestre
  - T1: Hasta 20 abril
  - T2: Hasta 20 julio
  - T3: Hasta 20 octubre
  - T4: Hasta 30 enero año siguiente

- [ ] Modelo 303 (IVA) - Si aplicable
  - Mismos plazos que modelo 130

### Anual
- [ ] Declaración de la Renta (modelo 100) - Abril a Junio del año siguiente
- [ ] Resumen anual IVA (modelo 390) - Si aplicable - Hasta 30 enero

## 🔍 Verificación de Datos

### Antes de Calcular
- [ ] Sumar todos los ingresos brutos del trabajo
- [ ] Sumar todas las retenciones del trabajo
- [ ] Sumar todas las facturas emitidas (por trimestre y total)
- [ ] Sumar todas las retenciones de facturas
- [ ] Sumar todos los gastos deducibles justificados
- [ ] Verificar que no faltan documentos

### Cálculo Previo
- [ ] Usar calculadora IRPF para estimación
- [ ] Comparar con año anterior (si procede)
- [ ] Identificar posibles errores o inconsistencias

## 📝 Notas Importantes

1. **Conservar Documentación**: Guarda todos los justificantes al menos 4 años
2. **Originales vs Copias**: Hacienda puede requerir documentos originales
3. **Digitalización**: Es recomendable escanear todos los documentos
4. **Asesoramiento**: En caso de duda, consulta con un asesor fiscal
